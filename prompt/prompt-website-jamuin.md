# PROMPT: Bangun Website "Jamuin" (Halaman Utama)

Buat halaman utama (landing page) untuk brand **Jamuin**, minuman herbal jamu modern.
Gunakan referensi visual berikut sebagai acuan gaya:

- **Referensi 1**: Website produk minuman kaleng dengan hero section gradasi warna, layout minimalis, kartu produk bulat/rounded, tipografi besar dan bold untuk judul, warna-warna pastel/vibrant per varian produk, section "tentang" dengan badge kecil (pill shape) berisi kandungan nutrisi.
- **Referensi 2**: Foto lifestyle dengan pencahayaan alami, nuansa hangat, komposisi produk dipegang langsung, kesan hidup sehat dan ceria. Gaya tipografi tebal, huruf kapital pada tagline pendek.

## Konsep Halaman Pertama (Hero)
- Kombinasikan **foto produk minuman (dari gambar yang saya lampirkan)** dengan **background putih polos** — bukan gradasi warna seperti referensi 1, tapi tetap elegan dan minimalis.
- Layout: judul besar di kiri atau tengah, foto produk sebagai focal point, banyak whitespace, tidak ramai.
- Kesan keseluruhan: **elegant, clean, minimalis**, bukan playful/ceria seperti referensi 2.

## Struktur Halaman
1. **Navbar**: logo Jamuin, menu (Tentang, Produk, Pesan, Kontak), tombol CTA "Pesan Sekarang".
2. **Hero Section**
   - Judul besar: **"Jamuin, Hidup Sehat Demi Dunia Akhirat."**
   - Subjudul singkat (satu kalimat pendukung, tone hangat tapi elegan).
   - Foto produk minuman dengan background putih (gunakan gambar yang saya lampirkan sebagai referensi komposisi/pencahayaan).
   - Tombol CTA: "Pesan Sekarang" dan "Selengkapnya".
3. **Section "Tentang Jamuin"**
   - Gunakan copy berikut (jangan diubah maknanya, boleh disesuaikan panjang baris untuk layout):

     > Jamuin lahir dari kekayaan warisan jamu Nusantara, minuman herbal yang telah menjadi bagian tak terpisahkan dari kehidupan masyarakat Indonesia selama berabad-abad, merajut keseimbangan harmonis antara tubuh, alam, dan tradisi leluhur yang terus dijaga hingga kini.

     > Setiap tegukan Jamuin lahir dari racikan rempah pilihan seperti kunyit, jahe, dan temulawak, diramu dengan resep turun-temurun yang telah teruji secara alami, kini hadir pula dalam varian kopi herbal yang memadukan kenikmatan kopi dengan manfaat kesehatan rempah tradisional.

   - Tambahkan beberapa badge/pill kecil berisi kandungan (Kunyit, Jahe, Temulawak, Kopi Herbal) mengikuti gaya badge di referensi 1, tapi warnanya disesuaikan ke palet netral/earthy agar tetap elegan.
4. **Section "Varian Produk"**
   - Grid 3 kolom menampilkan varian produk (kaleng/cup) dengan nama varian, mirip referensi 1 (kartu produk + tombol lihat detail).
5. **Section CTA / Form Pemesanan**
   - Ajakan memesan, form singkat (Nama, No. HP, Pesan), tombol "Kirim".
6. **Footer**
   - Logo, menu singkat, ikon sosial media.

## Panduan Gaya Visual
- **Warna dasar**: putih/off-white sebagai dominan, aksen warna earthy (kuning kunyit, cokelat jahe, hijau daun) secukupnya — jangan penuh warna seperti referensi 1.
- **Tipografi**: judul besar, tebal, sedikit elegan (bisa serif untuk judul + sans-serif untuk body, atau sans-serif modern konsisten).
- **Whitespace**: banyak ruang kosong, jangan padat.
- **Rounded corner** untuk kartu produk dan tombol, mengikuti kesan lembut seperti referensi 1.
- **Foto produk**: latar putih bersih, bayangan lembut (soft shadow), fokus pada produk.

## Teknis
- Gunakan HTML + CSS (atau React jika project sudah berbasis React) — sesuaikan dengan struktur project yang sudah ada di folder ini.
- Pastikan responsive untuk mobile.
- Gunakan gambar produk yang saya sediakan di folder assets (sebutkan path file gambar yang akan saya taruh).
- Buat komponen terpisah per section agar mudah diedit ke depannya.

Tolong buatkan struktur file dan kode halaman utama sesuai spesifikasi di atas.
